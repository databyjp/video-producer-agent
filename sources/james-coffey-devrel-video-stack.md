# The DevRel Video Stack — James Coffey

## Key Points

### Treat Video Like Software
- Configure environment → Write spec → Build in chunks → Optimize runtime → Release & iterate.
- Repeatable pipeline prevents "every video feels like a special project."

### Stage 1: Setup (Configure the Environment)
- One switch for lights, mic peaking around −12 dB, consistent background.
- Save scene presets. 10-second clap test before recording. Goal: film on demand, not fiddle with gear.

### Stage 2: Script (Write the Spec)
- **Skip word-for-word scripts.** Bullet outline keeps you conversational.
- Hook in first 10–20 seconds, 3–5 bullets per section, single CTA.
- Outline = spec: enough structure to know "done," room to adapt when demos take you somewhere better.

### Stage 3: Film (Build in Chunks)
- Film like you edit: 60–90 second segments.
- Re-slate when restarting (visible cue for timeline).
- Call out B-roll you owe your future self ("zoom on logs," "terminal close-up").

### Stage 4: Speak Naturally (Optimize the Runtime)
- Steady breath before starting, eyes to lens, clean sentence endings.
- Review own footage like a performance log: note energy drops, rushing, micro-pauses that improved clarity.

### Stage 5: Edit & Release
- **Edit for clarity first.** Cut ramble and redundancy, then layer only what improves comprehension.
- Publish V1 same session. Then handle: captions, chapters, thumbnail/title, end screen.

### Stage 6: Telemetry (Measure & Learn)
- Core metrics: Watch time, AVD, APV, retention curve, CTR, traffic sources.
- Cadence: 24h (CTR & early drop), 7d (traffic mix, retention), 28d (loyalty).
- After each release, note one improvement to test next time.

## Relevance to Production Guidelines
- Bullet outlines > word-for-word scripts for authenticity.
- Film in modular chunks, edit for clarity first.
- Measurement cadence as lightweight habit, not heavy process.
